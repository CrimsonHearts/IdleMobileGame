# 🖥️ Local Setup

Everything runs on your machine — no cloud needed. Pick a way to run the game,
then (optionally) generate painted character art with your local ComfyUI.

## Prerequisites
- **Node.js 18+** (`node -v`) — the only hard requirement to run the game.
- **Docker Desktop** — optional, if you prefer a container.
- **ComfyUI** (native) — only if you want to generate painted portraits (uses
  your GPU). You already have this.

---

## 1. Run the game locally

**Option A — plain Node (simplest, offline, no installs):**
```bash
node tools/static-server.mjs        # → http://localhost:8080
```

**Option B — Docker (containerized game, uses your host ComfyUI for art):**
```bash
docker compose up                   # → http://localhost:8080
```
Edits to `www/` are live (the repo is mounted). Stop with `Ctrl+C`.

> You can also just open `www/index.html` directly in a browser, but a server
> (A or B) avoids file:// quirks. Save data lives in the browser's localStorage.

---

## 2. Generate painted character art (local, GPU)

Art is generated by **your native ComfyUI** (full M4 GPU speed) and saved into
`www/assets/portraits/`. The game loads it automatically; vector art is the
fallback until the files exist.

1. **Start ComfyUI** (native, not in Docker — Docker can't use the Mac GPU):
   ```bash
   cd /path/to/ComfyUI && python main.py     # API at http://127.0.0.1:8188
   ```
   Make sure a checkpoint exists in `ComfyUI/models/checkpoints/` (a
   guofeng/xianxia or Animagine XL SDXL model — see docs/CHARACTER-ART.md).

2. **Generate** — either natively or from the container:
   ```bash
   # Native (simplest):
   node tools/gen-portraits.mjs --list          # see your installed models
   node tools/gen-portraits.mjs --gender=female # generate female leads
   node tools/gen-portraits.mjs                 # all 10

   # …or from inside the Docker container (reaches host ComfyUI):
   docker compose run --rm game node tools/gen-portraits.mjs --gender=female
   ```

3. **Reload** the game — painted leads appear per Spiritual Root. Commit them:
   ```bash
   git add www/assets/portraits && git commit -m "Add painted portraits"
   ```

Knobs: `--ckpt="Model.safetensors"`, `--steps=40 --cfg=6.5`, `--only=female-chaos`.
Full art guide + prompts: **docs/CHARACTER-ART.md** · backend details: **tools/README.md**.

The same ComfyUI/Leonardo setup also generates the 5 Rift Guardian boss
portraits (Round 29) — `node tools/gen-guardians.mjs`, saves to
`www/assets/guardians/`. See **docs/CHARACTER-ART.md**'s "Rift Guardian art"
section.

## 3. Build native mobile apps (still local)

See the README's Capacitor section and **docs/STORE-CHECKLIST.md**:
```bash
npm install
npm run cap:add:android      # needs Android Studio
npm run cap:sync && npm run open:android
```

## Quick reference
| Task | Command |
|------|---------|
| Run game (Node) | `node tools/static-server.mjs` |
